# Locadora artwork

Raster pixel art, generated with Google's Nano Banana 2.1 (`gemini-nano-banana-2.1`)
from our own prompts, then keyed to transparency and packed to WebP by hand.
Nothing here is a screenshot or a copy of someone else's artwork. The controllers
and cartridges are homages to the shapes of the era, not logos: none of the images
carries a brand name, a logo or a character.

| File | What it is |
|---|---|
| `street-dusk.webp` | Hero scene: the locadora on a Brazilian street at dusk (1376x768) |
| `shop-interior.webp` | Inside the shop, racks, counter, CRT (1376x768), the shelf's backdrop |
| `boxart-key.webp` | 80s airbrushed key art, for share cards and the splash (1376x768) |
| `pad-nes/snes/gb/gba.webp` | Controllers, transparent background |
| `cart-blank.webp`, `cart-gb.webp` | Cartridge blanks with an empty label, transparent |
| `tv-crt.webp`, `neon-sign.webp`, `rack.webp` | Props, transparent |
| `console.webp` | Top-loading console with an open cartridge slot, transparent (onboarding step 4, load screen) |
